University Timetable Clash Detector Using Python

Project Overview

The University Timetable Clash Detector is a Python-based application designed to identify scheduling conflicts in university class timetables.

Features

- Add course details
- Manage class schedules
- Detect timetable clashes
- Identify room conflicts
- Identify instructor conflicts
- Identify student batch conflicts
- Display clash reports

Technologies Used

- Python
- CSV
- Tkinter
- Jupyter Notebook

Project By

Anindita Mukherjee

BCA, Brainware University

How to Run

1. Download the repository.
2. Open the Jupyter Notebook.
3. Run all cells from top to bottom.
4. Follow the instructions displayed by the application.

Project Purpose

This project helps universities manage class schedules efficiently and reduce timetable conflicts.
